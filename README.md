# BOT01

Este es un proyecto para analizar el mercado y probar estrategias de inversión usando Python.

## Características
- Descarga datos de Yahoo Finance.
- Aplica estrategia de cruce de medias móviles.
- Realiza un backtest simple.
- Visualiza el precio, SMA y el crecimiento del capital.
